# Predictive History — Verbatim Returned Source-Caption Archive

This complete archive covers **191 of 191 discovered uploads** from [Predictive History](https://www.youtube.com/@PredictiveHistory). Each transcript is sorted into its recurring series folder (for example, `Civilization/`) and begins with the exact YouTube video URL on line 1.

## Preservation method

The transcript body contains each caption text segment **exactly as returned by the source API, in returned order**. No translation, summarization, cleanup, spelling correction, generated transcription, or inferred text was used. A newline separates returned source segments; it is archive structure only. The original response JSON is retained under `raw_api_responses/` for each video, including the provider’s timestamps/durations and returned language metadata.

## Scope of “unaltered”

> The source API response is the authoritative preservation record. The text field of every returned caption cue/segment is copied without alteration and in order. The transcript Markdown adds only the required source-video URL and blank separator. Raw JSON retains the provider-returned timing and segment boundaries for independent inspection.
